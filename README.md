# SQA-Lab

A small sample web project created for the Software Construction and Development (SCD) Lab.

## Project Purpose
This project demonstrates a simple student task manager that can be uploaded to GitHub and used for basic software quality practice.

## Files
- `index.html` - Main webpage
- `style.css` - Page styling
- `script.js` - Task manager functionality

## How to Run
Open `index.html` in a web browser.

## Lab
This project is prepared for the GitHub practical:
1. Create the `SQA-Lab` repository.
2. Upload these project files.
3. Commit the changes.
